# Forkable World Profile

This is my personal profile for the [Forkable World OS](https://github.com/forkable-world/forkable-world-os) project.

## Structure
- `profile.md` - Main profile with Schema.org metadata
- `interests/` - Detailed write-ups about interests
- `projects/` - Project documentation
- `contributions/` - Contributions to the world OS
- `agent/` - AI agent configuration

## Validation
This profile follows Schema.org standards and is automatically validated. To validate locally:

```bash
npm install
npm run validate
```
